# Exact Coloring of Claw-Free Graphs: The Role of Structural Representations

Research code and experimental data accompanying the paper **“Exact Coloring of Claw-Free Graphs: The Role of Structural Representations”** by Aneta Wróblewska (Maria Curie-Skłodowska University, Lublin, Poland).

The project compares exact coloring of a line graph `G = L(H)` with edge coloring of its reconstructed root graph `H`, as well as selected claw-free graphs that are not line graphs. The implemented methods are:

- Exact DSATUR branch-and-bound on `G`;
- **V-edge:** integer-programming vertex coloring with edge constraints;
- **V-clique:** integer-programming vertex coloring with maximal-clique constraints;
- **E-star:** integer-programming edge coloring of the reconstructed root graph using star constraints and Vizing's theorem.

**Important:** For class-II root graphs, E-star determines the *exact chromatic number* using an infeasibility proof for `Δ(H)` colors and Vizing's theorem, but does not output an explicit `(Δ(H)+1)`-edge-coloring. The vertex models produce an explicit coloring when successful.

## Repository contents

| Location | Contents |
|---|---|
| `claw_recognition.py` | Recognition of claw-free graphs and claw certificates |
| `line_graph_recognition.py` | Root reconstruction, line-graph recognition, and verification |
| `graph_parameters.py` | Structural measurements |
| `dsatur_exact.py` | Greedy and exact DSATUR |
| `coloring_backends.py` | HiGHS-based mixed-integer programming and optional CP-SAT backend |
| `vertex_coloring.py` | V-edge and V-clique models |
| `edge_coloring.py` | E-star model |
| `graph_generation.py` | Seeded generators for experimental sets A and B; enumeration for C |
| `experiments.py` | Experiment runner; writes a row per graph to CSV |
| `analysis.py` | Analysis and production of tables and figures |
| `tests/test_all.py` | Automated tests |
| `data/results/` | Original result CSVs, logs, and summaries |
| `paper/` | LaTeX source, bibliography, tables, figures and PDF |

### Test sets

- **A:** 1,125 line graphs generated from Erdős–Rényi, bipartite, tree, regular, and subdivided-regular root families.
- **B:** 240 selected claw-free graphs that are not line graphs (co-bipartite and complements of graphs from a triangle-free process).
- **C:** all 5,639 connected claw-free graphs on at most nine vertices, up to isomorphism.

These counts refer to the supplied results and the parameter choices in the commands below.

## Installation

Install Python and create a virtual environment (recommended). From the project root:

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip install pytest
```

The original experiments were reported using Python 3.13.16, NetworkX 3.6.1, NumPy 2.5.3, SciPy 1.18.1, a Linux machine with two 2.3 GHz Xeon cores and 7 GB RAM. The dependency file uses minimum versions rather than a frozen environment, so execution under other versions may produce different timings or require adjustments.

## Tests

```bash
python -m pytest tests -q
```

## Reproduce experiment data

Run the following commands **from the repository root**:

```bash
python experiments.py --set C --max-n 9 --time-limit 30 --workers 2
python experiments.py --set A --reps 15 --time-limit 30 --workers 2
python experiments.py --set B --reps 15 --time-limit 30 --workers 2
python analysis.py --backend highs
```

Experiment outputs overwrite `data/results/set_C_highs.csv`, `set_A_highs.csv`, and `set_B_highs.csv`, respectively; analysis updates the generated tables, figures, and `summary_highs.txt`. Preserve a copy of the supplied original results if you wish to compare runs. Wall-clock times vary with hardware, software, concurrency, and background load.

The graph generators use deterministic, fixed seeds defined in `graph_generation.py` (`base_seed=1000` for A, `base_seed=5000` for B); the line-graph vertex permutation is also seeded in `experiments.py`. Set C is generated by enumeration.

### Rebuild the manuscript (optional)

The `paper/` folder contains LaTeX sources. With a suitable TeX installation and `latexmk` available:

```bash
cd paper
latexmk -pdf -bibtex claw_free_coloring.tex
```

### Optional CP-SAT backend (experimental)

```bash
python -m pip install ortools
python experiments.py --set C --max-n 9 --time-limit 30 --workers 2 --backend cpsat
```

**The CP-SAT backend was not used for the results in the paper and was not independently validated in the original experiment environment.** Validate it on set C before using it for comparisons.

## Reproducibility and scope

This repository includes the generating code, deterministic seeds, output CSVs, and scripts for aggregating results. The comparisons concern the specified generated instance families, not all claw-free graphs. Timing results are implementation- and machine-dependent. See the manuscript's methodology and limitations sections before interpreting speedups.
